# Dependencies and attribution

The CPU Gaussian backend and browser viewer are original project code. They do not copy the original GRAPHDECO implementation or include pretrained weights. The method is inspired by [Kerbl et al. (2023)](https://arxiv.org/abs/2308.04079).

Direct Python dependencies are NumPy, SciPy, Pillow, OpenCV (headless), PyCOLMAP, FastAPI, Uvicorn, and python-multipart. Tests also use pytest and httpx. Exact versions used for this release are captured in `requirements-lock.txt`; upstream package distributions carry their license files and transitive notices. COLMAP/PyCOLMAP provides camera recovery and is not embedded into the browser.

- [NumPy license](https://github.com/numpy/numpy/blob/main/LICENSE.txt)
- [SciPy license](https://github.com/scipy/scipy/blob/main/LICENSE.txt)

- [FastAPI license](https://github.com/fastapi/fastapi/blob/master/LICENSE)
- [Uvicorn license](https://github.com/Kludex/uvicorn/blob/main/LICENSE.md)
- [python-multipart source](https://github.com/Kludex/python-multipart)

The demo’s staged Gaussian archive room and textured SfM captures are generated by this repository’s scripts. No third-party photos, real case evidence, or pretrained model weights are distributed. The original banner is labeled AI-generated; product screenshots show the running application.

GPU gsplat was considered but is not integrated in this release. No claims are made that this fixed-isotropic RGB backend reproduces full anisotropic 3DGS training or the performance of the original paper.
